# CrowdFunding

# 💰 Crowd Funding Platform

A simple and responsive **Crowd Funding web application** that allows users to explore fundraising campaigns, understand project goals, and support ideas financially. This project is built as part of my learning and portfolio to demonstrate frontend development skills.

---

## 🚀 Project Overview

The **Crowd Funding Platform** is designed to showcase how crowdfunding websites work. It provides a structured interface where users can view campaigns, understand funding requirements, and learn about project creators.

This project focuses on **clean UI, responsive design, and organized code structure**.
